# `src/evaluation`
`metrics.py` — MAE/RMSE (USD, lower is better) and R² (higher is better; can be negative; not an accuracy %),
percentile-bootstrap confidence intervals, subgroup error table with sample counts and a small-sample (<30) flag.
`plots.py` — comparison, predicted-vs-actual, residual and importance figures. `eda.py` — EDA statistics/figures.
