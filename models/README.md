# `models/`
Generated by `python -m scripts.train_model --overwrite`: `coverwise_model.joblib` (full fitted preprocessing + estimator
pipeline) and `model_metadata.json` (model ID, params, dataset/artifact SHA-256, schema, CV + hold-out metrics,
importance, library versions, timestamp, seed). Binaries are git-ignored by default; the app verifies the checksum before
loading. Never load a joblib file you did not create.
